# Halodial for Homebrew

```sh
brew install --cask halodial/tap/halodial
```

Installs [Halodial](https://halodial.github.io), a dial for your Mac that opens under your pointer, and opens without
the "Apple could not verify" prompt. Halodial updates itself after that.
